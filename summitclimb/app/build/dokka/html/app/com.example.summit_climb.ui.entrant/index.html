@Composable
fun CampsiteDetailsScreen(navController: NavController, campsiteId: String, currentUserId: String, searchController: CampsiteSearchController, lotteryController: EntrantLotteryController)

The entrant's campsite details screen (US 01.01.05, 01.01.06, 01.02.01, 01.02.02, 01.13.01). Styled like the owner's details screen (com.example.summit_climb.ui.owner.OwnerCampsiteDetails) but with entrant actions: full details, amenities, availability, rules and policy, the active lottery with a Join or Leave button, and 1–5 star rating. Icons are vector drawables in res/drawable (ic_arrow_back, ic_location, ic_star_, ic_amenity_), so this screen doesn't need the Material icon library.
