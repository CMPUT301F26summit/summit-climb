UserRepository

class UserRepository(db: FirebaseFirestore = FirebaseFirestore.getInstance())

Handles the Firestore operations for user profiles. Firestore stores users in a users collection. Each document's ID is the user's device based User.userId. A snapshot listener keeps users up to date for the admin screens.

Example:

val deviceId = FirebaseAuth.getInstance().currentUser?.uid ?: ""
userRepository.getOrCreateUser(deviceId) { user ->
    println("Hello ${user.name}")
}
