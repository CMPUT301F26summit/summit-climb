Campsite

data class Campsite(var id: String = "", var name: String = "", var location: String = "", var maxOccupancy: Int = 0, var avgRating: Double = 0.0, var ratings: Map<String, Int> = emptyMap(), var description: String = "", var amenities: List<String> = emptyList(), var tags: List<String> = emptyList(), var price: Double = 0.0, var promoImageUrl: String = "", var rules: String = "", var cancellationPolicy: String = "", var ownerId: String = "", var latitude: Double = 0.0, var longitude: Double = 0.0, var availableDates: List<String> = emptyList(), var bookedDates: List<String> = emptyList(), var activeLotteryId: String? = null, var listingStatus: ListingStatus = ListingStatus.PENDING, var adminNotes: String = "")

A campsite that entrants can find, view and join lotteries for. Campsites are stored in the Firestore campsites collection. The document ID is not stored inside the document CampsiteRepository will copy it into id after loading. Every property has a default value Dates in availableDates and bookedDates use the format yyyy-MM-dd,

availableBetween
Link copied to clipboard
fun availableBetween(startDate: String, endDate: String): Boolean

Checks whether every date from startDate to endDate is free. Both dates are included. A date is free when it is in availableDates and not in bookedDates. Example: with startDate = "2026-11-03" and endDate = "2026-11-05", the dates Nov 3, 4 and 5 must all be free.

filterMatch
Link copied to clipboard
fun filterMatch(filter: CampsiteFilter): Boolean

Checks whether this campsite matches a filter of location, date range and number of guests. Every part of the filter must match. Empty parts of the filter always match. Example: val campsite = Campsite(location = "Jasper, AB", maxOccupancy = 6, availableDates = listOf("2026-11-03", "2026-11-04")) campsite.matchesFilter(CampsiteFilter(location = "jasper", guests = 4)) // true campsite.matchesFilter(CampsiteFilter(guests = 8)) // false, too many guests
