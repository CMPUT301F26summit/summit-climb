CampsiteFilter

data class CampsiteFilter(val location: String = "", val startDate: String = "", val endDate: String = "", val guests: Int = 0)

The filter an entrant sets on the campsite list screen. Leave a field empty (or guests at 0) to not filter by it. Dates use the format yyyy-MM-dd, for example 2026-11-03. Example: campsites in Jasper for 4 people from Nov 3 to Nov 5, 2026: val filter = CampsiteFilter( location = "Jasper", startDate = "2026-11-03", endDate = "2026-11-05", guests = 4 )
