CampsiteFilter
Link copied to clipboard
data class CampsiteFilter(val location: String = "", val startDate: String = "", val endDate: String = "", val guests: Int = 0)

The filter an entrant sets on the campsite list screen. Leave a field empty (or guests at 0) to not filter by it. Dates use the format yyyy-MM-dd, for example 2026-11-03. Example: campsites in Jasper for 4 people from Nov 3 to Nov 5, 2026: val filter = CampsiteFilter( location = "Jasper", startDate = "2026-11-03", endDate = "2026-11-05", guests = 4 )

CampsiteRepository
Link copied to clipboard
class CampsiteRepository

Handles the Firestore operations for campsites. Firestore stores campsites in a campsites collection. A snapshot listener keeps campsites up to date, so any screen that reads it is redrawn when Firestore changes. Screens need call this class (by CampsiteSearchController) instead of working with Firestore directly.

CampsiteSearchController
Link copied to clipboard
class CampsiteSearchController(campsiteRepository: CampsiteRepository)

Handles what an entrant does when finding campsites: search, filter, view details and rate. Screens call this class instead of CampsiteRepository directly. Example: val controller = CampsiteSearchController(campsiteRepository) val results = controller.searchCampsites("lake", CampsiteFilter(location = "Jasper", guests = 4))
