FirestoreLotteryRepository

class FirestoreLotteryRepository(db: FirebaseFirestore) : LotteryRepository

Purpose: saves and loads lotteries using the Firestore "lotteries" collection. Entrants are stored in each lottery's "entries" subcollection (added later). Known problems: It downloads ALL lotteries, then filters on the phone. It starts watching Firestore when created and never stops.
