CampsiteRepository

class CampsiteRepository

Handles the Firestore operations for campsites. Firestore stores campsites in a campsites collection. A snapshot listener keeps campsites up to date, so any screen that reads it is redrawn when Firestore changes. Screens need call this class (by com.example.summit_climb.controller.CampsiteSearchController) instead of working with Firestore directly.

Example: val repository = CampsiteRepository() val pineLake = repository.getCampsite("campsite1")
